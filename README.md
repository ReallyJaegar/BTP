# BTP

So in this project we have tried to reprocude the cultureadapt pipeline as proposed in the paper Crossroads of Continents. But since we do not have access to LLM APIs hence we have tried to implement the pipeline using open source models. The original cultureadapt pipeline proposed takes input an image and uses GPT4V APIs to extract the necessary elements visible in the image. Then the image is passed onto GroundingDINO which basically creates bounding boxes for the elements visible. The next task is to create the masks for the objects that have to replaced(The question herein lies how do we know which object to change and which not to---I think we do a brain for this task,something like GPT). The masks are then passed onto an impainting model , in this case stable diffusion2 and we get the transcreated image. 

We have also tried to implement a similar thing. The modularity of the pipeline allows us to easily swap the elements while keeping the ultimate outcome or original intent the same. So firstly instead of the GPT4V APIs we have used the Recognize Anything Model(RAM) which is open source and very good at identifying things.For the code you can check [test_ram.py](cultureadapt_ram/test_ram.py) or [USING_RAM.ipynb](Notebooks/USING_RAM.ipynb).The outcome for [img4.png](cultureadapt_ram/img4.png) for example are "bowl . broccoli . broth . fill . food . meat . noodle . onion . parsley . pork . soup . stew . vegetable . white .". These will be used in the next step. 

For the bounding boxes we have used GroudingDINO only. The prompt for this step and the inpainting process are stored in [edit_config.json](change_pic/edit_config.json).The output for this stage will be something like [annotated_image.jpg](change_pic/annotated_image.jpg).

The next stage is to create the masks for the parts to be replaced by the impainting model. The impainting model that we have used for now is stable-diffusion-inpainting.The output for [img4.png](cultureadapt_ram/img4.png) will look something like [inpainting_image_Brazil.jpg](change_pic/inpainting_image_Brazil.jpg).


The code for the groundingDINO stage and the mask creation and impainting model are in the [edit.py](change_pic/edit.py).We have used the Ananconda prompt or miniconda3 environment for running the files because RAM requires python 3.8 and groundingDINO and stable diffusion require python 3.10. Moreover we also faced a lot of version conflicts.
